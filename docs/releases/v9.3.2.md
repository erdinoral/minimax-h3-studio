# H3 Studio 9.3.2 — Chapter sequences and cooperative render pause

## Director chapter sequences

With Continuum enabled, **Sequence grouping → One video per chapter** processes the chapter's scenes as ordered native chunks. Six five-second scenes produce one 30-second sequence, with each scene's own prompt and reference assignment. Only the first starting image is applied; intermediate New-cut starting images remain saved but are not applied in this mode. **Split at new cuts** retains the previous behavior and remains the default for existing projects.

The native limit remains 16 chunks and nine unique reference images per sequence. A longer chapter splits into ordered sequences; the next sequence uses the previous output's last frame, which is not saved native motion/audio context. There is no promise of seamless continuity between separate jobs. Existing queued jobs are unchanged.

Video details and continuation choices show the total native sequence duration while running, rather than only its chunk duration. Scene cards show the actual configured seconds instead of a fixed one-minute label. Spectrum blend buttons and inputs in the mirrored Scene settings now forward to the existing settings handlers.

## Render pause (#19)

**Pause render**, next to Stop, waits at a sampling progress checkpoint and resumes the same prompt execution. It does not interrupt, submit a replacement render, modify tensors, wrap the model, or change native saved-prefix signatures. **Pause after current render** remains a separate queue control.

An in-progress step must finish before the pause is acknowledged. Model/latent memory remains allocated; this does not free VRAM or suspend a model-loading stage. Stop remains effective while paused. Studio renews a 30-second lease; if the controller disconnects, the engine automatically resumes after lease expiry. It is not a durable pause across an application shutdown. The boot shim installs the bundled control integration on restart, without model downloads or edits to ComfyUI core files.

## Production diagnostics (#28)

Open a video's **Prompt → Diagnostic report** to download a small JSON report with Studio status, cancellation source/time, model names, effective Spectrum settings and available engine-completion evidence. It excludes prompt text, reference images, local paths, API keys and raw logs, and does not upload anything. Missing history is reported as unavailable, not as successful completion. Exporting a report does not change job status or restart a render.

The 9.3.1 cancellation/completion race fixes remain in place. The original no-input CANCELLED report and visual drift still require evidence from the affected installation; this release does not claim that a local successful render establishes their cause.

## Validation

239 Python tests and 46 JavaScript tests pass, with syntax and whitespace checks. A real Director native two-section draft at 864×480 completed as one eight-second, 192-frame video after pausing for six seconds with an unchanged sampler step and resuming the same prompt ID. The status finished as done. This is functional validation, not cinematic-quality or speed acceptance.

Hybrid selection (#21) was verified through the live API: both H3 model slots changed together and encoder/VAE choices stayed intact. The original model selections were restored. No model download or feature-film render was performed for this check.
