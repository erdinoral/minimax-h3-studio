# H3 Studio 9.1.1

## Director production

- Empty chapters now include an Add scene button that places the new scene in that chapter.
- Produce all queues eligible scenes across chapters; Produce chapter queues only its chapter.
- Empty production controls stay disabled, with clearer scene/chapter/all labels.
- Chapter action buttons share the same height and alignment.

## Short clips

- Scene and individual Director scenes accept 2- and 3-second clips.
- H3 renders its four-second frame schedule, then FFmpeg trims the video and optional audio to the requested duration. Generation time is therefore similar to a four-second clip.
- Continuations use the last frame of the trimmed clip.

## Support

- The Support panel links to Erdin's shared Buy Me a Coffee page.
- Open Collective and GitHub Sponsors payment buttons have been removed.
- Star the repository is a styled button. Bug and idea reporting remain available.

## Updating

Run Update in Pinokio, stop and start Studio, then reload the browser.
Existing projects and generated media remain in place.

Validation: six Director JavaScript checks and ten Python checks covering short clips, production validation and character identity. Short-clip checks include real FFmpeg trimming with and without audio.

Experimental Hybrid model and 30-second generation changes are not included in this release.
