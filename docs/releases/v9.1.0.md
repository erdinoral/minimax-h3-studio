# H3 Studio 9.1.0

The new Appearance controls are now included in the public update. Open **Settings → Appearance** to select a color palette and interface style independently.

## Appearance and guidance

- Orange, Blue and Graphite palettes.
- Modern, Old School and Studio styles change typography, corners and controls.
- Preferences persist in the current browser.
- A bilingual in-app Guide explains Scene audio, Director, references and final assembly.

## Audio, references and assets

- Scene supports a single uploaded audio clip as a generation reference or as the original soundtrack attached to the output. Original-audio attachment does not create lip synchronization.
- Character and asset selection fixes keep only the intended cast and references in each shot; matching library entries can be reused rather than generated again.
- The H3/Qwen asset switch separates video-derived stills from Qwen image generation. Referenced Qwen views are generated individually through Image Edit.
- Selecting a source image stages it for preview; generation waits for an explicit action. Deletion and polling fixes prevent removed images from reappearing.
- Chapter production validates its queue before generating assets, with clearer continuation and scene-edit handling.

## LoRAs and optional tools

- Categorized adapters, local Civitai key entry and validated optional downloads.
- Selected character adapters and trigger words follow the intended scene cast in Scene and Director.
- New LightX2V FL2V/Ref2V speed adapters apply compatible step, strength and sampler recipes automatically. Only one speed recipe can be selected at a time.
- Experimental HyperFlow uses its required model patch and sampler schedule rather than an ordinary LoRA loader.
- A shared RefMod switch in Scene, Director and Settings enables cached full visual references. It does not train a LoRA or guarantee identity preservation.
- Optional Look Sheets and native AV continuation workflows are available through Film Tools. Studio's existing Continue action is not automatically replaced by those separate workflows.
- Model storage provides guarded deletion of individual managed weight files. Active/default files and queued-job dependencies are protected.

## Update

Use **Update** in Pinokio, then stop/start Studio and reload its page. Tool installation does not automatically download the optional adapter weights. Download desired adapters through Settings or the optional LoRA installer.

Speech identity, pronunciation, lip sync and image identity remain model-dependent. HyperFlow and the optional advanced workflows need validation on each setup. Automatic transcription and burned-in subtitles are not included in this release.

Validation: 164 Python tests and 27 JavaScript tests passed. Launcher/frontend syntax checks passed. RefMod with LightX2V and experimental HyperFlow completed local video smoke tests; this does not establish comparative output quality.
