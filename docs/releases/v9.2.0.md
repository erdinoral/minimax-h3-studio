# H3 Studio 9.2.0

## Spectrum acceleration

- Optional Spectrum installation is included in Install and Update, pinned to commit `806fe498d574a726fecb8818917f00a4b993fd77`.
- Spectrum ON/OFF control appears below Video engine in Scene and Settings, with its own styling and Experimental badge.
- English and Turkish labels update when the interface language changes.
- Disabled by default. Applies to new native single-clip H3 graphs after model adapters; custom multishot sampling is unchanged.
- Video blend weight 0.50, audio blend weight 0.0, offline smoothing replay enabled. Generated motion and speech can change.
- A local RTX 5060 Ti 16 GB test at 1056×608, 14 steps and approximately 10 seconds took 1575.058 s without Spectrum and 966.344 s with Spectrum: 38.65% shorter total time. This is one matched pair, not a general performance guarantee. Generated media and personal reference images are not distributed.

## Experimental Hybrid engine

- H3 Hybrid selects the b25–49 checkpoint for both H3 model slots while retaining the existing encoder and VAEs.
- Reference mode with the Hybrid checkpoint offers experimental 30-second requests. This does not establish that high-resolution 30-second generation fits a 16 GB GPU.
- Hybrid r48 adapter uses its compatible loader. Other model engines remain selectable.
- See `docs/hybrid-h3.md` for model sources, verification and limitations.

## Validation and updating

180 Python tests and 32 JavaScript tests passed. Launcher syntax and whitespace checks passed.

Run Update in Pinokio, stop and start Studio, then reload the page. Existing local settings and generated media are retained. Spectrum installation requires a ComfyUI restart before enabling it.

Sliding-window long-video generation is not included in this release.
