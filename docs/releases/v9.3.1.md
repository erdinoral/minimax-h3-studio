# H3 Studio 9.3.1 — Director continuity and production reliability

Director scene references could point to the wrong image when a take used different character subsets or a first-frame guide. Reference labels now resolve to fixed Continuum V39 slots, preserving each scene's own reference order while the native sampler handles keyframe offsets.

## Director and generation

- Preserve imported scene order, distinct per-section prompts and New/Continue choices; AI Director plans a progressing story rather than repeating an introduction.
- Keep first-frame guides on New takes. Independent Continue takes require their own preceding Director scene, rather than the latest unrelated video.
- New Continuum reference geometry defaults to Match Output. Max Identity remains an explicit Director API choice; existing saved selections are retained.
- Production details distinguish saved native context, chunk count and last-frame handoff. Cross-job last-frame handoff does not transfer native motion/audio history.
- Saved native-prefix continuation retains its original keyframe contract, including prompt-only runs without a first frame; it does not introduce the parent video's last frame into that saved run.
- Retrying a New/image-guided job preserves its selected starting image. Independent continuation retries refresh their parent last-frame handoff; saved-prefix retries retain their original guide.
- Omit identical Action/Beats repetitions without removing distinct chronological beats.
- Spectrum presets and manual video blend preserve unrelated settings. Audio blend remains zero. Spectrum runs still cannot safely reuse persisted prefixes in this integration.
- Record the Spectrum settings actually submitted to the engine in each job and its Gallery entry, independently of later settings changes.

## Issue-related fixes

- Stop cannot accidentally target the following job during an asynchronous interrupt request. Completion during Stop is preserved; explicit cancellations record source/time.
- Legacy CANCELLED results can be recovered on startup only when Comfy confirms successful completion with a saved video. An MP4 alone is insufficient evidence. This does not establish the original cause of issue #28 or resolve visual drift.
- Hybrid and model catalogs recognize subfolders with correct relative loader paths. Known full-size Hybrid weights and alternate filenames are supported; incomplete files stay unavailable. Both H3 model slots change together, retaining encoder/VAE selections.
- Pause remains **after the current render**, not mid-render suspension. Issue #19 remains open.

## Validation and limitations

All 225 Python tests and all 39 JavaScript tests passed, with syntax and whitespace checks. Passing code tests is not proof of cinematic continuity, speech quality, or a general speed increase. No personal reference images or generated film files are distributed.

Local RTX 5060 Ti 16 GB smoke tests completed at 864×480, 8 steps, native audio and no LoRAs: two native 2×4-second runs and one two-job last-frame chain. Each assembled result contains exactly 192 frames / 8 seconds and 32 kHz audio. These are draft functional checks, not final-quality acceptance. Sampled frames retained the main appearance, but the fixed-camera instruction was not fully respected; Spectrum 0.60 examples showed translucent/double-image artifacts. The exact-prompt Spectrum-OFF control was interrupted when Pinokio, Studio and ComfyUI became unavailable, so no matched speedup or causal quality result is claimed. The interrupted test was retained and held for manual retry, with original settings restored. The user's feature-film production was not resumed or published. Audio presence was checked; listening quality was not assessed.

Update through Pinokio, stop/start Studio, then reload the browser. Existing projects, media and saved production settings are preserved. No new model download is required for these fixes.
