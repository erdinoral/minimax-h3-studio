# H3 Studio 9.3.0

## Video workflows

- Experimental native Continuum generation and continuation in Scene; optional Continuum backend in Director. Existing Multishot remains the Director default because framing and identity can still drift.
- H3 Refine in the player offers only resolutions higher than the source and saves a separate Gallery video. Enable capture before generating the source; existing MP4 files without captured state are not supported.
- Refine uses the H3-trained 3D latent upscaler and conservative Flow-Aligned resampling. Optional node versions and model weights are pinned by Film tools. See [workflow details](https://github.com/erdinoral/minimax-h3-studio/blob/main/docs/video-workflows.md).
