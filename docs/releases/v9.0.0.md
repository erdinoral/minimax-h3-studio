# MiniMax H3 Studio v9.0.0 — Film & AI Director

Create an editable film plan inside Studio, keep your cast and selected adapters attached to it, and use explicit references in both Scene and Director.

## Highlights

- AI Director turns a story and target duration into a validated film package using your configured LLM. It adds new scenes in a separate chapter, preserves existing cards and LoRA/voice assignments, and leaves production under your control. JSON import/export remains supported.
- Shared character, location, creature and vehicle reference selection in Scene and Director. Continuations keep the previous final frame first in the reference graph; standalone Scene only auto-matches film assets when enabled.
- Character LoRA mode skips character sheet generation and excludes the card's old images while enabled. Name and voice remain editable.
- Categorized LoRA selectors, available trigger metadata, usage guidance and independent weights for up to three selected adapters. Existing catalog downloads are reused.
- Optional H3 Singularity main-model switching in Settings. Approximately 21 GB, separate download, experimental; not installed by default. The switch affects future jobs and retains the encoder/VAEs.
- Four vehicle views: front, rear, right and left. Improved individual asset-image deletion and gallery navigation.
- Shot review with read-only repair previews before applying changes; reference video/audio excerpts without overwriting originals.
- Wider Settings forms, responsive LoRA cards and expanded TR/EN localization.
- Gemini streamed text now preserves word boundaries, including exact character and location names.
- Includes the latest main-branch H3 graph API compatibility fix.

## Updating

Stop Studio, select **Update** in Pinokio, start again, then use **Ctrl+F5** in the browser. Existing models and saved projects are retained; do not use Reset for this update. Configure a reachable LLM provider to use AI Director. Optional models and LoRAs are downloaded separately.

This release does not guarantee identical faces across every shot or uninterrupted long videos. Singularity's quality advantage has not been established. Shot review checks the written plan, not rendered video quality.

## Validation

Python and JavaScript regression suites cover film imports, planning validation, continuation wiring, explicit asset manifests, LoRA selection/weights, optional models, review previews, gallery navigation and translations. Live AI planning and import were also checked using a temporary film store.
